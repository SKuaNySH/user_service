# Наставничество и участие в мероприятиях

## Стек технологий

- Java 17
- Spring Boot, Spring Web и REST API
- Spring Data JPA и Hibernate
- PostgreSQL
- Gradle
- JUnit 5, Mockito и AssertJ для тестирования

## Наставничество

Базовый путь API: `/api/mentorships`.

| Метод | Путь | Действие |
|---|---|---|
| `POST` | `/{mentorId}/{menteeId}` | Назначить наставника пользователю; повторное добавление уже существующей связи не создает дубликат. |
| `GET` | `/{userId}/mentees` | Получить список подопечных наставника. |
| `GET` | `/{userId}/mentors` | Получить список наставников пользователя. |
| `DELETE` | `/{menteeId}/{mentorId}` | Удалить связь наставничества. Удалить ее может только наставник или подопечный. |

Нельзя назначить пользователя наставником самому себе.

## Участие в мероприятиях

Базовый путь API: `/api/event/{eventId}/participations`.

| Метод | Путь | Действие |
|---|---|---|
| `POST` | `/register/{userId}` | Зарегистрировать пользователя на мероприятие. Повторная регистрация отклоняется. |
| `POST` | `/unregister/{userId}` | Отменить регистрацию. Пользователь может отменить только собственное участие; отмена возможна, если он зарегистрирован. |
| `GET` | `/count` | Получить количество участников. |
| `GET` | (базовый путь) | Получить список участников мероприятия. |
